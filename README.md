# Мой кабинет

Личный кабинет массажного кабинета «Тишина тела». Статическая страница GitHub Pages подключается к Supabase для защищённой синхронизации после входа по ссылке из электронной почты.

Код приложения публикуется открыто. Данные клиентов в репозиторий не добавляются: они хранятся отдельно в Supabase и ограничены RLS-политиками для владельца.
